Segmented Button

Material Design 3 segmented button for single or multi-select options between 2 to 5 items. Not intended for top-level route navigation between pages.

Note: MD3 Expressive (May 2025) replaces segmented buttons with connected button groups. Consider using button groups for new projects.

Selection Modes

Segmented buttons support three selection modes for different use cases, enabling compact mutually exclusive or multi-select controls in a single row.

Single Select (Default)

Only one segment can be selected at a time

Day Week Month Year

Selected: none

  <ds-segmented-button-segment value="day">Day</ds-segmented-button-segment>

API

Attributes - ds-segmented-button

Attribute Type Default Description
selection string 'single' Selection mode: 'single' (one at a time), 'multi' (multiple), or 'required' (one always selected)
density string 'default' Density level: 'default' (40px), '-1' (36px), '-2' (32px), or '-3' (28px)
disabled boolean false Disables all segments

Attributes - ds-segmented-button-segment

Attribute Type Default Description
value string '' Value for this segment (required)
selected boolean false Whether segment is selected
disabled boolean false Whether segment is disabled
icon string '' Icon text/emoji to display

Events

Event Detail Description
change { value: string | string[] } Fired when selection changes. Single mode returns string, multi mode returns array

CSS Parts

Part Description
container Main container element
button Individual segment button

Accessibility

Keyboard Interaction

Key Context Expected Result
Tab Segmented group present Moves focus into and out of the group
Arrow Keys Focus on a segment Moves focus between segments
Space / Enter Focus on a segment Toggles or selects the focused segment

Semantics

  • Uses role="group"; segments expose selection state with aria-pressed.
  • Screen readers announce selection state and position.
  • Focus indicators meet WCAG 2.2 requirements and support reduced motion preferences.

Usage Guidelines

  • When to use: Use segmented buttons for compact option sets where users switch or combine modes quickly.
  • When not to use: Avoid for large option counts, long labels, or top-level route navigation.
  • Composition: Keep groups to 2-5 segments, use clear labels/icons, and choose single, multi, or required mode based on task constraints.
  • Common mistakes: Overcrowded segments and ambiguous icons reduce discoverability. Prefer concise, explicit labels.

Props

ds-segmented-button

  • selection: single (default), multi, or required
  • density: default, -1, -2, or -3
  • disabled: disables all segments

ds-segmented-button-segment

  • value: value for this segment (required)
  • selected: whether segment is selected
  • disabled: whether segment is disabled
  • icon: icon text/emoji to display

Events

  • change: fired when selection changes; detail.value contains selected value(s)
