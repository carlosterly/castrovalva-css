Combobox

Material Design 3 combobox for selecting from a list of options with optional search and multi-select. Not intended for free-form long text entry where arbitrary values are expected.

Basic Usage

Use a combobox to choose from a short or filtered list. It combines text input and option selection in one compact control for faster discovery.

API Reference

Attributes

Attribute Type Default Description
open boolean false Whether the dropdown is visible
multiple boolean false Allow multiple selections
searchable boolean true Enable search input
disabled boolean false Disable interaction
placeholder string "Select an option" Text shown when no option selected
value string|array null Selected value(s)

Properties

Property Type Description
open boolean Get/set whether the dropdown is open
multiple boolean Get/set multiple selection mode
searchable boolean Get/set search input visibility
disabled boolean Get/set disabled state
value string|array Get/set selected value(s)

Events

Event Detail Description
ds-combobox:change { value, values } Fired when selection changes
ds-combobox:open — Fired when the dropdown opens
ds-combobox:close — Fired when the dropdown closes

Slots

Slot Description
option Option elements for selection

Methods

Accessibility

  • ✅ Keyboard navigation with arrows, Enter, Escape
  • ✅ Uses listbox and option roles for screen readers
  • ✅ Announces selection changes via aria-selected
  • ✅ Focus returns to the trigger after close

Usage Guidelines

When to Use

  • When users need to search a list of options
  • For multi-select filters or tag selection
  • When options should show custom labels or metadata

When Not to Use

  • For very short lists where a simple select is faster
  • For binary choices where a checkbox or switch fits better

Best Practices

  • Keep option labels concise and scannable
  • Provide search when lists exceed 7-10 items
  • Use meaningful values in the data-value attribute
