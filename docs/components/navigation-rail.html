Navigation Rail

Navigation rails provide persistent vertical navigation for tablet and desktop layouts, supporting 3–7 primary destinations with optional header content and a floating action button. Not intended for mobile phone layouts — use ds-navigation-bar at narrow viewports instead.

Basic Usage

A rail with three destinations. One destination is active. The rail sits along the side of the viewport, keeping navigation visible without consuming the full width of a drawer.

Home Search Favorites 
<ds-navigation-rail>
  <ds-navigation-rail-item icon="home" value="home" active>Home</ds-navigation-rail-item>
  <ds-navigation-rail-item icon="search" value="search">Search</ds-navigation-rail-item>
  <ds-navigation-rail-item icon="favorite" value="favorites">Favorites</ds-navigation-rail-item>
</ds-navigation-rail>

Usage Guidelines

  • When to use: Tablet and desktop layouts with 3–7 primary destinations of similar importance, where a full navigation drawer would be too heavy but a bottom bar too small.
  • When not to use: Avoid on mobile phone viewports — use ds-navigation-bar instead. Avoid when destinations are fewer than three or more than seven.
  • Composition: Always keep exactly one destination active. Use the header slot for branding or a menu toggle. Use the FAB slot for a primary action that remains accessible at all times.
  • Common mistakes: Using icon-only items without visible labelling — show labels on the active item at minimum. Exceeding seven destinations makes the rail feel crowded.

API

DSNavigationRail

Container component for rail destinations.

Slots

Slot Description
header Content above destinations (logo or menu trigger)
fab Floating action button below destinations
(default) Destination items (ds-navigation-rail-item)

Events

Event Detail Description
ds-navigation-rail:select { value: string, label: string } Fired when a destination is selected

CSS Parts

Part Description
container The navigation rail container
destinations Wrapper for destination items

DSNavigationRailItem

Individual navigation destination item.

Attributes

Attribute Type Default Description
value string - Value for this destination
icon string - Material Symbol icon name
label string - Destination label (or use slot content)
active boolean false Marks the destination as active
disabled boolean false Disables the destination
badge string - Badge content (number or text)

Events

Event Detail Description
ds-navigation-rail-item:click { value: string, label: string } Fired when item is clicked (not disabled)

CSS Parts

Part Description
container The item container button
icon The icon element
label The label text
indicator The active indicator
badge The badge element

Accessibility

Keyboard Interaction

Key Context Expected Result
Tab Any Moves focus to the next rail destination
Shift+Tab Any Moves focus to the previous rail destination
Enter / Space Focus on a destination Activates the destination and fires the select event

Semantics

  • The rail uses role="navigation"; each item uses role="tab".
  • Active items expose aria-selected="true"; disabled items expose aria-disabled="true".
  • Destination labels are visible on the active item; all items carry a descriptive aria-label.
