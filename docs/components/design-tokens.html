Design Tokens

Core design values that define the visual foundation of the design system. This page turns the token reference into a practical visual showcase so semantic roles, type styles, spacing, motion, and shape choices are easier to evaluate in context.

How to Read This Page

Tokens work best when shown as relationships, not isolated values. Color roles are presented as semantic pairs, typography is shown as complete specimens with line-height and tracking, and system utilities like spacing and size are shown as reusable scales.

Semantic first Use --md-sys-* roles in components instead of hardcoded values.
Utilities stay global Use --ds-space-* and --ds-size-* for rhythm and control sizing.
Pairs matter on-* roles are foreground tokens and should be previewed on their matching surfaces.

Usage Example

Foundation tokens should be combined semantically. A surface should pair its background, text color, spacing, radius, and elevation instead of mixing unrelated values. 

.token-card {
  background: var(--md-sys-color-surface-container-low);
  color: var(--md-sys-color-on-surface);
  padding: var(--ds-space-4);
  border-radius: var(--ds-radius-md);
  box-shadow: var(--md-sys-elevation-level1);
  transition:
    box-shadow var(--md-sys-motion-duration-short2)
      var(--md-sys-motion-easing-standard),
    background-color var(--md-sys-motion-duration-short2)
      var(--md-sys-motion-easing-standard);
}
