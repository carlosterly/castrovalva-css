Navigation Bar

Bottom navigation bars allow movement between primary destinations in an app. They are ideal for mobile, appearing at the bottom of the screen with 3–5 destinations. Not intended for desktop layouts; use ds-navigation-rail or ds-navigation-drawer for wider viewports.

Basic Usage

A basic navigation bar with three destinations. One destination is always active. The bar sits at the bottom of the viewport providing persistent access to top-level sections without requiring a drawer or sidebar.

Usage Guidelines

  • When to use: Mobile apps with 3–5 primary destinations of equal importance where persistent tab-level switching is needed without a page reload.
  • When not to use: Avoid on desktop — use ds-navigation-rail or ds-navigation-drawer instead. Do not use for more than five destinations or for secondary navigation within a section.
  • Composition: Always keep exactly one destination active. Pair short, universally understood icons with brief labels. Reserve badges for actionable notification counts only.
  • Common mistakes: Using more than five items makes the bar feel crowded. Avoid hiding or disabling the bar mid-flow — persistent presence builds orientation for mobile users.

API

DSNavigationBar

Container component for navigation items.

Events

Event Detail Description
ds-navigation-bar:select { value: string, label: string } Fired when a destination is selected

CSS Parts

Part Description
container The navigation bar container

DSNavigationBarItem

Individual navigation destination item.

Attributes

Attribute Type Default Description
value string - Value for this destination
icon string - Material Symbol icon name
label string - Destination label (or use slot content)
active boolean false Whether destination is active
disabled boolean false Whether destination is disabled
badge string - Badge content (number or text)

Events

Event Detail Description
ds-navigation-bar-item:click { value: string, label: string } Fired when item is clicked (not disabled)

Part Description

Accessibility

Keyboard Interaction

Key Context Expected Result
Tab Any Moves focus to the next navigation item
Shift+Tab Any Moves focus to the previous navigation item
Enter / Space Focus on an item Activates the destination and fires the select event

Semantics

  • The bar uses role="navigation"; each item uses role="tab".
  • Active items expose aria-selected="true"; disabled items expose aria-disabled="true".
  • Each item includes a descriptive aria-label for screen reader users.
