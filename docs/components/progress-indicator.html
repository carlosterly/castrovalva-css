Progress Indicator

Material Design 3 linear and circular progress indicators for determinate and indeterminate loading states. Not intended as a generic spinner replacement when no meaningful progress or activity context is available.

Basic Usage

Use linear or circular progress with a determinate value. Choose form factor based on available space and content flow. 

<ds-linear-progress value="45"></ds-linear-progress>
<ds-circular-progress value="45"></ds-circular-progress>

Initial Value

Configure max range and custom color for startup states.

<ds-linear-progress value="30" max="80" color="secondary"></ds-linear-progress>
<ds-circular-progress value="30" max="80" color="secondary"></ds-circular-progress>

API

Attributes

Element Attribute Type Default Description
ds-linear-progress value number 0 Current progress value.
ds-linear-progress max number 100 Maximum progress value.
ds-linear-progress indeterminate boolean false Displays animated indeterminate state.
ds-linear-progress color string primary primary, secondary, tertiary, error.
ds-circular-progress value number 0 Current progress value.
ds-circular-progress max number 100 Maximum progress value.
ds-circular-progress indeterminate boolean false Displays animated indeterminate state.
ds-circular-progress size string | number md sm, md, lg, aliases small/medium/large, or pixel value.
ds-circular-progress color string primary primary, secondary, tertiary, error.

Properties

Property Type Description
value number Get/set current value.
max number Get/set maximum value.
indeterminate boolean Get/set indeterminate mode.
color string Get/set indicator color scheme.
size (circular) string Get/set circular indicator size token or pixel value.

Methods

Method Description
getProgress() Returns current progress percentage clamped to 0-100.

Semantics

  • Uses role="progressbar" with aria-valuemin and aria-valuemax.
  • Determinate mode exposes aria-valuenow; indeterminate mode omits it per ARIA guidance.
  • Add labels via aria-label or aria-labelledby when context is ambiguous.

Usage Guidelines

  • When to use: Use determinate indicators when measurable progress is available and indeterminate indicators for unknown-duration work.
  • When not to use: Avoid perpetual loaders without contextual feedback or completion outcomes.
  • Composition: Prefer linear indicators in flowing layouts/forms and circular indicators in compact or centered loading surfaces.
  • Common mistakes: Switching between determinate and indeterminate states without context can confuse users.
