Switch

Material Design 3 toggle switch for binary on/off states with smooth animations and clear visual feedback. Not intended for multi-option selection; use checkboxes or radios for those scenarios.

Basic Usage

Use switches for binary settings. This is the recommended baseline because switches communicate on/off state more directly than a checkbox and apply the setting immediately without requiring a submit action. 

<ds-switch id="switch-basic"></ds-switch>
<label for="switch-basic">Enable alerts</label>

Variants

Use icons when the state should be explicit.

With Icons

Shows a checkmark for the on state.

  • Use when: The on/off status needs extra clarity, especially in accessibility-sensitive contexts.
  • Avoid when: Simple context makes the state self-evident and icons would add visual noise. 
<ds-switch show-icons></ds-switch>
<ds-switch checked show-icons></ds-switch>

Sizes

Use size to align with layout density.

<ds-switch size="sm"></ds-switch>
<ds-switch size="md" checked></ds-switch>
<ds-switch size="lg"></ds-switch>

States

Show on, off, and disabled states clearly.

On and Off

Default switch behavior with on and off states.

<ds-switch></ds-switch>
<ds-switch checked></ds-switch>

Disabled

Switches can be disabled in both on and off states.

<ds-switch disabled></ds-switch>
<ds-switch checked disabled></ds-switch>

API

Attributes

Attribute Type Default Description
checked boolean false Whether the switch is on.
disabled boolean false Whether the switch is disabled.
show-icons boolean false Whether to show the selected icon.
size string "" Size of the switch (sm, md, lg).

Properties

Property Type Description
checked boolean Get or set the checked state.
disabled boolean Get or set the disabled state.
showIcons boolean Get or set whether icons are shown.
size string Get or set the size.

Events

Event Detail Description
ds-switch:change { checked: boolean } Fired when the switch state changes.

Methods

Method Returns Description
toggle() void Toggle the switch state.

Accessibility

Keyboard Map

Key Context Expected Result
Tab Switch not focused Moves focus to the switch.
Space / Enter Switch focused Toggles on/off state and emits change event.

Semantics

  • Uses role="switch", aria-checked, and aria-disabled.
  • Screen readers announce the on/off state.
  • Visible focus indicator supports keyboard navigation.

Usage Guidelines

  • When to use: Immediately-applied binary settings such as notifications, dark mode, or Wi-Fi.
  • When not to use: Actions that need explicit confirmation before taking effect; use a button and dialog.
  • Composition: Always pair with a visible label so the setting is clear without interaction.
  • Common mistakes: Using switches for multi-select or non-binary choices, and omitting labels.
