API

Functions

Function Purpose
getElevation(level) Get box-shadow value for a level (0-5)
getCSSVariable(level) Get CSS custom property name for a level
applyElevation(element, level) Apply elevation directly to element
applyElevationVar(element, level) Apply elevation using CSS custom property
removeElevation(element) Remove elevation from element
getElementElevation(element) Get current elevation level from element
applyElevationWithTransition(element, fromLevel, toLevel, duration) Apply elevation with smooth animation

ElevationManager Class

Manages elevation with automatic state changes on interaction.

Method Purpose
constructor(element, options) Create manager with configuration
setElevation(level) Set elevation with transition
getElevation() Get current elevation level
reset() Reset to default elevation
updateOptions(options) Update configuration
detach() Remove event listeners

Configuration Options

Options passed to ElevationManager constructor:

Option Type Default Description
defaultLevel number 0 Base elevation level
hoverLevel number 2 Elevation on hover
activeLevel number 3 Elevation when pressed/active
focusLevel number 2 Elevation on focus
duration number 300 Transition duration (ms)

Semantics

  • Elevation is visual only and should be paired with semantic cues.
  • Use sufficient contrast and explicit focus indicators alongside shadow changes.
  • Compatible with mouse, touch, and keyboard interactions.

Usage Guidelines

  • When to use: Use elevation to communicate hierarchy, interactive affordance, and transient state changes like hover or drag.
  • When not to use: Avoid relying on elevation alone for critical state or grouping differences.
  • Composition: Keep elevation levels consistent across similar surfaces and transition smoothly between states.
  • Common mistakes: Jumping across too many levels creates visual noise and weakens hierarchy.
