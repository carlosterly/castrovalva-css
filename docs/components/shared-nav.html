Shared Navigation

Prototype shared navigation shell for component documentation pages. This demonstrates a persistent navigation drawer with component categorization.

Features

  • Persistent drawer with state storage
  • Responsive variant switching (modal on mobile)
  • Active page highlighting
  • Grouped navigation items by category
  • Collapsible sidebar control

Integration

This navigation component can be integrated into individual component documentation pages to provide consistent navigation across the design system.
