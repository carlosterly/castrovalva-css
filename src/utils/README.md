# Utilities

Helpers that components build on, usable directly in application code.

| Utility | What it does | Docs |
| --- | --- | --- |
| [`animation-presets.js`](./animation-presets.js) | 31 motion presets, MD3 duration and easing tokens, promise-based API | [live](../../docs/components/animation-presets.html) · [notes](./animation-presets.README.md) |
| [`drag-drop.js`](./drag-drop.js) | Draggable elements and drop zones with mouse, touch and keyboard support | [live](../../docs/components/drag-drop.html) · [notes](./drag-drop.README.md) |
| [`elevation.js`](./elevation.js) | Programmatic control of MD3 elevation levels and surface tints | [live](../../docs/components/elevation.html) · [notes](./elevation.README.md) |
| [`focus-ring.js`](./focus-ring.js) | Consistent, token-driven focus indicators | [live](../../docs/components/focus-ring.html) · [notes](./focus-ring.README.md) |
| [`ripple.js`](./ripple.js) | MD3 ripple state-layer effect | used internally by interactive components |

Full API reference, options and live examples are on the linked documentation
pages.
